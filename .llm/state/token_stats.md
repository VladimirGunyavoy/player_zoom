# Token Usage Stats

> Статистика расхода токенов по сессиям.
> Заполняется в конце каждой сессии.
> Формат: старт → до рутины → после рутины

---

## Как читать

- **Старт** — сколько токенов было потрачено к началу сессии (%)
- **До рутины** — сколько потрачено перед запуском рутины (%)
- **После рутины** — сколько потрачено после завершения рутины (%)
- **Работа** = До рутины − Старт
- **Рутина** = После рутины − До рутины
