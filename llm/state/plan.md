## 📝 Заметки

### Почему llm/ структура важна:
- Проект будет развиваться через множество диалогов
- Каждый новый агент должен быстро входить в контекст
- Главная цель: **минимизировать размер контекста**
- Вторая цель: давать **адекватный контекст** для работы

### Принципы организации:
- **Краткость** - TL;DR сначала, детали потом
- **Структура** - четкая навигация, предсказуемые места
- **Актуальность** - обновлять state/ файлы каждую сессию
- **История** - history/ append-only, не удалять старое
